COMPUTER PROFESSIONALS — GITHUB PAGES WEBSITE

Upload all seven files from this folder directly to your GitHub Pages
repository. Keep index.html, contact.html, services.html, how-it-works.html,
styles.css and script.js together in the same directory, along with this README.

CONTACT BUTTONS (contact.html)

- Send Email: opens their default email application, addressed to j.c63821998@gmail.com.

- Facebook page fallback: https://www.facebook.com/profile.php?id=61594138724238

The three contact buttons work through standard URLs; GitHub Pages does not
need any server-side code. Messenger depends on Facebook accepting the Page ID
and the customer having Messenger available or being signed in. Test Messenger
on a phone after publishing, because Facebook does not permit a live chat test
from this build environment.

DEPLOYMENT
1. Extract the ZIP archive.
2. Upload the seven extracted files (not the ZIP) into the repository's Pages
   publishing folder (usually the repository root).
3. Commit. If necessary, configure Settings > Pages > Deploy from a branch.
4. Open contact.html on your github.io site to test the contact buttons.
